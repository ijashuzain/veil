# AdMob Ads Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add consent-gated AdMob adaptive banners and native template ads to Veil on Android and iOS without affecting web, premium playback, auth, or content pagination.

**Architecture:** A testable `AdService` owns UMP, Mobile Ads initialization, SDK ad loading, and disposal wrappers. A Riverpod controller exposes readiness and privacy-options state; shared banner/native widgets own loaded-ad lifecycles. Reusable linear-list and sliver-grid components inject native slots after each 12 organic items while screen code controls placement.

**Tech Stack:** Flutter 3.41+, Dart 3.11, Riverpod 3, `google_mobile_ads 9.0.0`, Google UMP, Android manifest metadata, iOS Info.plist. Version is pinned exactly because upstream `9.1.0` breaks iOS framework builds through `GoogleMobileAds_Beta.h`.

## Global Constraints

- Android and iOS only; web must compile and remain ad-free.
- Show ads to every user, including premium users.
- Debug/profile builds use official Google test ad-unit IDs; release uses supplied production IDs.
- Keep onboarding, recovery, own Profile/settings, and fullscreen playback ad-free.
- Never request ads before UMP `canRequestAds()` succeeds.
- Failed or unavailable ads occupy zero space and do not retry in a loop.
- Ads never affect repository requests, pagination offsets, content counts, or organic indexes.
- Do not request ATT or add `NSUserTrackingUsageDescription`.
- Do not hand-edit generated plugin registrants or other generated Dart files.
- Do not create git commits unless user explicitly requests them.

- `test/ad_service_test.dart`: consent/controller success and fail-closed behavior.

- [ ] **Step 5: Implement UMP and SDK initialization**

```dart
await _requestConsentInfoUpdate();
await _loadAndShowConsentFormIfRequired();
final canRequestAds = await ConsentInformation.instance.canRequestAds();

    .getPrivacyOptionsRequirementStatus();
```
